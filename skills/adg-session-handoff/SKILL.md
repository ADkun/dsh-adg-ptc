# 把当前会话交接给一个全新会话

结论：交接的**唯一产物是一份交接提示词**。新会话除了这份字什么都没有 —— 没有本会话的对话记录、没有临时文件、没有工具状态、没有你对项目建立起来的「感觉」。所以判据只有一条：**一个零上下文的新会话只读这份字，能不追问、不重走已经排除的路，直接接着干。**

## 触发与产物

- **触发**：用户输入 `/adg-session-handoff`，或说「交接 / 开新会话接着做 / 给我一份能带到新会话的交接提示词」。
- **产物**：一段**可整块复制**的交接提示词，直接贴在回复正文、用带 `text` 语言标注的代码块整块给出（便于一键复制）。用户明确要求存文件时才写文件。
- **不是产物**：整段对话的逐字誊抄、会话日志、压缩摘要原文。这些是素材，不是交接。
- **目标本身就没说清时**：若本会话里从没明确过「到底要做什么」，先向用户问清再写 —— 交接词再工整，目标错了也是白交。

## 先记住：新会话看不到的东西

| 你看得见 | 新会话看得见吗 | 怎么办 |
|---|---|---|
| 本会话的对话与工具结果 | 看不到 | 把结论、证据锚、原始报错写进提示词 |
| 你的临时工作目录 / 半成品文件 | 除非写了绝对路径，否则找不到 | 有用的产物写**绝对路径**；没价值的不提 |
| 已登录的网页窗口 / 桌面会话 / 后台作业 | 看不到，也未必还在 | 需要登录态就写「需用户在有头窗口重新登录」；后台作业写「已终止 / 需重跑」 |
| 「我刚才试过 X，不行」这类过程记忆 | 看不到 | 失败过的路 + **原始失败签名**写进「不要做什么」 |
| 已被压缩掉的历史细节 | 你也可能记不清 | 去取回，别凭印象（见下节） |

## 提炼来源：只从当前会话取，且以磁盘现状为准

- **事实只从本会话取**：用户原话（带消息 ref 或时间）、工具返回值原文、子代理的结算结论、当前文件内容。
- **细节记不清或已被压缩**：先用 `search_context` 定位、再 `decompress` 取回（本会话装了 billion-context，这两个工具才在；PTC 下经 `run_code` 调）。取回的是历史记录，不是当前真相。
- **「我记得改过」不算数**：产物以**现在磁盘上的内容**为准 —— 交接前 `read` / `grep` 一次关键文件，写它此刻的真实状态。
- **引用别人的实测要写明来源**：子代理报的、用户转述的，写「据 X 报」，不写成自己验证过。
- **给不出证据锚的「已完成」降级为「可能未完成」**，不写成事实。

## 交接提示词的结构（按这个顺序写，能删则删）

开头先让新会话进入角色（固定写清「你在接手一个进行中的任务，以下是你需要的全部上下文」），再按下面九节给料。每节的判据是「删掉它，新会话会不会做错或得多问一句」。

| # | 节 | 写什么 | 判据 |
|---|---|---|---|
| 1 | 你在接手什么 | 一句话任务 + 现在到哪一步（结论前置） | 读第一段就知道在干嘛、进度几何 |
| 2 | 目标与验收标准 | 做成什么样算完；可程序化验证的给出验证命令 | 能据此判断「做完没有」 |
| 3 | 硬约束 | 用户明说过的：版本、不许动的范围、格式 / 风格 / 语言、时间约束。带原话或 ref | 违反就会被退回的每一条都在这里 |
| 4 | 已定决策与理由 | 选了什么、否了什么、为什么（`选 A 不选 B，因为 C`） | 不会推翻已定的取舍重来 |
| 5 | 当前状态与产物 | 已完成清单；每个产物给**绝对路径**（文件可加符号名 / 小节名定位）；验证到什么程度：命令 + 退出码 / 原始报错 | 能直接打开产物、知道哪块可信 |
| 6 | 环境事实 | 工作目录、preset / 权限模式、可用工具面、关键依赖版本、需要的登录态或凭据（**不写密码 / 密钥 / cookie**） | 不会因为环境不对第一步就踩空 |
| 7 | 未决问题与开放 TODO | 用户已授权但没做完的、被卡住的、需要用户拍板的 | 没有一件事掉在地上 |
| 8 | 不要做什么 | 已排除的方向、失败过的路 + **原始失败签名**（报错文本 / 退出码） | 不重蹈覆辙 |
| 9 | 下一步 + 起手句 | 最短的下一步；一句新会话可直接照做的第一句话 | 拿到就能立刻起手 |

## 写作纪律

- **自足**：不写「详见上文 / 前面说过 / 那个文件」这类新会话看不到的指代；凡它要用的，写全或给绝对路径。
- **证据锚**：每个「已完成 / 已修复」后面跟一个可复核的锚 —— 命令 + 退出码、文件 + 符号名、URL、原始报错。没有锚的，写成「未验证」。
- **诚实**：未确认的推断写「推断 / 未观测」，并给出**怎么量**；不把「应该没问题」写成结论。
- **决策带理由**：只写结论的决策，新会话会再问你一次「为什么不用另一种」，等于白交接。
- **面向行动**：结尾必须是可执行的第一步，不是「祝顺利」。
- **可删性**：只留会影响决策与动作的信息，能删的字删掉。交接词是作战简报，不是回忆录。
- **不含秘密**：密码 / token / cookie / 私钥不进提示词；需要凭据就写「用户会提供」或「需要重新登录」。

## 输出的样子

- 提示词本体用一个带 `text` 语言标注的代码块整块给出；块外只用一两句话说清：这是什么、怎么用（新开对话 → 选同一个 preset / 模式 → 把整块粘进去当第一条消息）。
- 用户要求保存到文件时：写到用户给的路径，正文仍同步贴出核心内容；不默认落盘、不留中间文件。

## 边界（不做什么）

- **不假装能开新会话**：本模式里 AI 开不了新会话，也不该说「已为你新建会话」。交接靠用户把提示词粘进新会话 —— 这一点如实写进块外的说明。
- **不誊抄对话**：逐字复制整段历史是日志，不是交接；也几乎一定超长、淹掉重点。
- **不写秘密**，不替用户保存凭据。
- **不把未验证的推断写成已完成**，不把子代理的说法转写成自己的实测。
- **不改项目本身**：交接只产出提示词，不顺手动代码 / 改配置（那是被交接任务的下一段，不是这一步）。

## 和 `/export` 的分工

`/export`（Web 端提供的斜杠命令）把**整个会话树**导出成 ZIP（原始日志，含子会话与附件），用于留存 / 审计。**本技能产出的是提炼过的作战简报** —— 新会话读它，不读日志。要留存原始日志就用 `/export`；要接着干活就用这份交接提示词。

## 未观测

- **未观测**：新会话按这份提示词续做的实际追问率与重走弯路率（本技能按「自足、证据锚、决策带理由」描述，未量化）。量法：连续几次交接后记两个读数 —— 新会话第一轮是否追问、是否重走了「不要做什么」里已排除的路。
- **未观测**：提示词篇幅与信息完整度的平衡点（越短越易读完，越长越可能漏掉关键约束）。量法：同一任务分别产出精简版与详尽版各交接一次，对比新会话的追问次数与出错次数。
- **未观测**：交接后新会话对「环境事实」的依从程度（会不会真按写明的权限模式 / 工具面去干，还是另起一套）。量法：抽一次交接，核新会话首次工具调用是否落在提示词写明的工作目录与工具面内。
