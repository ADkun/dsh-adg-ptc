# 完成一次文件与文档工作

## PTC：这些工具都在 `run_code` 里调

你的目录里只有 `run_code` 一个工具；**直呼 `read` / `glob` / `pwsh` 会解析成 `UNKNOWN_TOOL`**。本文下面所有工具名都写成程序里的嵌套调用：

```ts
const hits = await tools.grep({ pattern: 'TODO', path: 'D:/work' })
const files = await tools.glob({ pattern: '**/*.md', path: 'D:/work' })
const head = await tools.read({ file_path: hits[0].path, limit: 40 })
return files.slice(0, 10).map(f => f.path)   // 只回你要的那一点
```

四条 PTC 实操差别：

- **只 `return` / `console.log` 你要的**：`tools.read` 一次拉满整份文件、`tools.glob` 一次回上千条路径，全 `return` 出去等于把整个仓库灌进上下文。先在程序里筛（`slice` / `filter` / 正则），只回判据与下一步要用的路径。
- **无依赖的只读调用并发发**：`await Promise.all([tools.glob({...}), tools.grep({...})])`；有依赖的（先定位再读）必须 `await` 串行。
- **单个失败别连坐**：`tools.read` 对不存在的路径会 reject 成 `ToolCallError`（`.toolName === 'read'`），用 `try/catch` 接住继续跑其余文件 —— 一次读失败不该让整段程序白跑。
- **批量改文件要一次程序做完**：循环里 `await tools.write(...)` 全写在一段程序里，中途结果留变量；分多段程序来回对话，每一步都要重新交代上下文。
- **PTC 程序的 `process.env` 是空字典**：Node 侧读不到 `DSH_HOME` 之类；要环境变量就用 `await tools.pwsh({ command: '$env:DSH_HOME' })` 取（PowerShell 侧完整）。`run_code` 的 `timeoutMs` 默认 120s、上限 600s，长转换任务交给子代理或拆段。

你拿到的是文件与文档这条能力带的工具面：`read` `read_image` `write` `edit` `glob` `grep` `pwsh` `job_list` `job_output` `job_kill` `notify_user`（都在 `run_code` 里）。

**先读委派里写的【目标】/【要干什么】/【不要干什么】。** 这条工具面与「按已定方案改工作区代码并自测」那条能力带**逐字相同** —— 两者唯一的差别是委派写下去的目标。委派写明是改代码 / 跑编译测试的活，就照那条办（本技能不覆盖它）；委派写的是文档与文件，就照本技能办。

## 一、检索定位

- 按**文件名 / 路径**找：`glob`（路径模式）。
- 按**内容**找：`grep`（正则，返回匹配行与行号）。
- 按**时间 / 类型 / 大小**找：`pwsh` 的 `Get-ChildItem` 过滤（`-Filter` / `-Recurse` / `-Include` / `Where-Object` 的 `LastWriteTime`、`Length`）。只读探测用 `-File` / `-Directory`，不要顺手改动。
- **先探测再动手**：不确定目录结构时先列一层，不要凭猜路径写操作。（报告里给的是**绝对路径**，不是相对路径。）

## 二、深入阅读与问答

- 纯文本 / 代码 / 配置：直接 `read`；大文件用 `offset` / `limit` 分段读，不要一次拉满。
- **文本类文档（PDF / Word / Excel / PPT）用本机已有的工具提取文本后再读**，不要试图用 `read` 把二进制当文本读：
  ```powershell
  Get-Command pdftotext, soffice, libreoffice -ErrorAction SilentlyContinue
  Get-ItemProperty 'HKLM:\SOFTWARE\Classes\Excel.Application\CurVer' -ErrorAction SilentlyContinue
  ```
  哪一条存在就用哪一条（命令行工具、Office 自带的 COM 接口等）。**不要假设某一个一定存在** —— 先探测，缺什么就按「本机缺少 X」处置。
- 问答式深读：结论要能指回**页码 / 工作表 + 单元格区域 / 幻灯片号 / 章节**这些坐标，不要给「文档里提到过」这种无法复核的话。

## 三、批量整理归类

- 复制、移动、删除、重命名、按类型 / 日期分目录：一律**先列计划再执行**（`pwsh` 里先 `-WhatIf` 或用一次只列举的查询把目标集打出来）。删除与覆盖是**不可逆**动作，目标集必须在回答里列全。
- 交付里给**条数 + 失败清单**：成功 N 条、跳过 M 条（各自原因）、失败 K 条（各自原因），以及改动前后的路径。
- 同名冲突、路径长度、占用中的文件都是**正常失败**：如实报，不要静默改名或静默跳过。

## 四、格式转换与文档生成

- 常见转换：PDF↔Word、图片转 PNG、Excel↔CSV 等。同样**先探测本机有能力做这件事的工具**，再用它；缺工具就按「本机缺少 X」处置并给替代方案。
- 生成文档 / 表格 / 图表 / PPT：产出**给绝对路径**。生成后**回读一次**产物（`read` 文本类、或用提取工具读回）确认它不是空文件、不是 0 字节、不是只有标题 —— 「写了文件」不等于「文件有内容」。

## 五、图片内容理解：`read_image` 有两条互相独立的条件

要用 `read_image` 把图交给模型看时，先知道自己可能撞上哪一条：

1. **注册条件**：`read_image` 依赖持久 attachments 服务 —— **服务没挂上时这个名字根本没注册**。后果不是「看不了图」，而是**那一次委派会直接失败**（`names unknown global tool`）。这时要如实报给调度者、**不要自己反复重试同一条路径**。
2. **执行条件**：即便注册了，执行时还要求**当前会话路由声明图像输入**。没声明时它报错 —— 那就如实说明「看不了图」，**改用可查询的状态量作答**（文件名、大小、EXIF / 尺寸 / 颜色直方图 / 结构化的 OCR 文本输出等），**不要假装看过**。

两条都不满足时，「我判断这张图是……」这种结论只是猜测，必须显式标注为**推断**，不能写成观察结论。

## 六、取决于本机工具链的能力：先探测，缺什么就直说

OCR、人像 / 场景特征检索、跨设备传输这三类**不在工具面里**，能不能做完全取决于本机装了什么（Python 库、Office、同步盘目录等）：

```powershell
Get-Command python, tesseract, magick, ffmpeg, adb -ErrorAction SilentlyContinue
```

**探测到的才做**。缺什么就直说「本机缺少 X，无法完成」，并给替代方案（换一条已有的工具链 / 只交付能做的部分 / 请用户在本机补装后重派）。**不允许假装完成** —— 也不允许用别的相似产物冒充（比如用图片尺寸冒充「看懂了对人像的检索结果」）。

## 七、边界（不做什么）

- 工作区**代码**改动、需要跑编译或测试自证的活不是你的。
- 不改系统设置、不操作软件界面、不做需要登录的网页交互。
- 越界时**不要尝试、不要扩范围**；最终回答写明「超出能力范围」+ 你已核实的最小可交付事实。
- 需要用户本人动手的步骤（例如跨设备传输要在手机上确认）用 `notify_user` 发一条**单向**提醒（写清卡在哪 + 用户要做什么），然后把未决问题写进最终结果里报回调度者 —— 它是单向通知，不阻塞也不等回话，**不能**拿它代替用户确认。

## 八、验收标准

交付里给出：

- **改动的路径与操作前后状态**。
- 批量操作给**条数与失败清单**（成功 / 跳过 / 失败各自的条数与原因）。
- 生成或转换出的文件给**绝对路径**，并说明用什么回读过、回读结果是什么。
- 深读结论给**可复核的坐标**（页码 / 单元格区域 / 幻灯片号 / 章节）。
- 越界部分写明需要哪条能力带（哪种工具面）与已核实的最小事实。
- 未做到的部分、以及任何标注为**推断**的结论，必须保留 —— 不许静默交付。

- **未观测**：`read_image` 的注册条件（持久 attachments 服务没挂上时名字未注册）在本机的真实发生率。—— 量法：在一个没挂该服务的会话里派一次要求看图的委派，看它是拿 `names unknown global tool` 当场失败，还是照常看到图。
- **未观测**：`read_image` 的执行条件在当前会话路由下的通过率。—— 量法：在同一会话里 `read_image` 一张已知存在的 PNG，看它是返回图像内容还是报「不声明图像输入」。
